# Landing Page Institucional - Setec Marine Service

Landing page desenvolvida para a Setec Marine Service, com foco na apresentacao institucional de servicos, comunicacao digital e experiencia do usuario.

## Objetivo

O projeto foi criado para estruturar uma presenca digital voltada a apresentacao dos servicos da empresa, organizando informacoes relevantes de forma clara, visual e orientada a navegacao do usuario.

## Tecnologias utilizadas

- TypeScript
- CSS
- JavaScript

## Funcionalidades

- Apresentacao institucional da empresa
- Organizacao de informacoes sobre servicos
- Estrutura de navegacao entre secoes
- Layout voltado para comunicacao digital
- Chamadas para acao (CTAs), quando aplicavel

## Processo de desenvolvimento

Este projeto foi desenvolvido com apoio de inteligencia artificial utilizando Claude Code.

Minha participacao incluiu a definicao do objetivo da pagina, briefing, estrutura de conteudo, direcionamento visual, requisitos, revisao do resultado, testes e ajustes finais.

A inteligencia artificial foi utilizada como ferramenta de apoio ao desenvolvimento. O projeto foi revisado, adaptado e organizado para publicacao no GitHub.

## Como executar localmente

1. Clone este repositorio:

```bash
git clone https://github.com/Rhenan-amorim/LandingPage-Setec-MarineService.git
```

2. Acesse a pasta do projeto:

```bash
cd LandingPage-Setec-MarineService
```

3. Instale as dependencias:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

5. Abra o endereco informado no terminal no navegador.
